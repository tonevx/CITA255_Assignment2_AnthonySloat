# Assignment 2 — [A List of Things: Game Backlog Time List]

**Name:** Anthony Sloat

## What it does
The tool shows off a list of games/game series that I have yet to finish - and another list that displays the current amount of hours in those games. When the button is pressed at the very bottom of the application, it shows off the full amount of hours played in all of those games so far. Hopefully, I can take some of those games off of the backlog soon...

## How to run it
Open the .sln in Visual Studio, set the target to Windows Machine, press F5.

## Known issues
No known issues at the moment. Numbers are calculated correctly, and items line up with one another as intended. Foreach loop was checked via debugger tools in Visual Studio (screenshots within the project folder).
